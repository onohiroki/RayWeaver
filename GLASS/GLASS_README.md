## License notes

AGF files use an open text format published by each glass manufacturer, making the data easy to reuse. Many existing tools can read them.

License terms vary by source. Data obtained directly from glass manufacturer websites may be used under each provider's terms. However, AGF files bundled with the Zemax installer may be restricted by the Ansys Zemax EULA from use outside Zemax or redistribution.

In production use, always review the latest Ansys Zemax EULA and each data provider's terms of use, and consult your legal team if unclear.
